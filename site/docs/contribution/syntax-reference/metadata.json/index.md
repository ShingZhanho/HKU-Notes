# Metadata schema

Each document root contains `metadata.json`. **v3 is the only supported version**.
Validation uses the checked-in schema and does not access the network.

- [Schema v3](v3.md): current reference.
- [Schema v2](v2.md): historical, unsupported.
- [Schema v1](v1.md): historical, unsupported.

Legacy version markers and command fields are rejected.
