            \begin{solution}
                Statement \texttt{S1} will be executed $n-1=8-1=7$ times, so will statement \texttt{S3}.

                For statement \texttt{S2}, the number of times it is executed is the distance between the number at \texttt{A[$j$]} and its correct position (number of swaps required).

                \textbf{Worst-case:} occurs when the array is sorted in descending order.

                At the time of execution for \texttt{$x=$A[$j$]}, the subarray \texttt{A[1], A[2], $\ldots$, A[$j-1$]} is already sorted.
                Suppose \texttt{A[$j$]} is the $k$-th largest among \texttt{A[1], A[2], $\ldots$, A[$j$]}, for $k=1, 2, \ldots$, $j$.

                Note that the inner \texttt{while} loop shifts numbers larger than $x$ to the right.
                Therefore, for each $x$, \texttt{S2} will be executed $k-1$ times.
                Let the $t$ be the random variable denoting the number of executions for \texttt{S2}, and $t\sim\text{Uniform}(1, j)$.

    // Returns the counterfeit coin and whether it is heavier (true) or lighter (false).
